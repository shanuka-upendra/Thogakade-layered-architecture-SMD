# 📚 Thogakade – Layered Architecture (SMD)

**Thogakade-layered-architecture-SMD** is a Java project demonstrating a classic **layered software architecture** pattern. The application separates responsibilities into distinct layers to improve readability, maintainability, and modular development.

---

## 🚀 Overview

This project applies layered architecture principles where each layer has a specific responsibility and interacts only with adjacent layers. It’s a clean structure ideal for understanding how large applications can be organized for clarity and scalability.

---

## 🗂️ Project Structure
```
src/
├── ui/ # Presentation / UI layer
├── controller/ # Application logic
├── model/ # Domain models and entities
├── service/ # Business logic services
├── util/ # Helper utilities
└── main/ # Application entry point
```
